# Snublesten i Danmark – arbejdsregister (24. okt 2026)

snublesten_register.xlsx  – registret med fanerne Oversigt, Register, Afvigelser, Mangler og Felter
snublesten_register.csv   – samme 210 rækker som ren tekst (til GitHub / kortet)
snublesten_register.geojson – de 187 sten med koordinat, klar til MapLibre/Leaflet

Kilder: snublesten.dk (183 sten med koordinat og nedlæggelsesår), snublestenfyn.dk (Odense, Assens,
Svendborg-Skårup, Nyborg), de.wikipedia "Liste der Stolpersteine im Großraum Kopenhagen" (73 tyske
indskriftsoversættelser), Wikidata (10 items), OpenStreetMap (18 noder), Wikimedia Commons (fotos).

Ikke indsamlet endnu: Fredericia, Aalborg, Tønder, Skærbæks fulde liste, Frederikshavn.
Navne, adresser og datoer er fakta; biografier og fotos er ikke kopieret.
Registret bør ikke publiceres som eget datasæt før aftale med grupperne.

De tidligere filer wikidata_dk_2026-10-24.csv og osm_dk_2026-10-24.csv er råudtræk og kan beholdes som kildebelæg.
